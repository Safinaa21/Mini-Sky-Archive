# Mini Sky Archive

Mini Sky Archive merupakan aplikasi Android sederhana menggunakan Custom ListView untuk menampilkan koleksi foto objek langit yang diambil secara pribadi.

## Tampilan Aplikasi

![Mini Sky Archive](mini-sky-archive.jpeg)

## Fitur

- Custom ListView
- Menampilkan foto objek langit
- Menampilkan nama dan deskripsi
- Menampilkan tanggal pengambilan foto
- Fitur pencarian berdasarkan nama atau deskripsi

## Teknologi

- Java
- Android Studio
- Android SDK
- Custom ListView
